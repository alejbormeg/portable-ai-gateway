# Contributing

Thank you for your interest. During the initial dual-license phase, this project accepts:

- reproducible bug reports;
- feature and interoperability requests;
- deployment feedback that contains no credentials or sensitive data;
- responsible security reports through [SECURITY.md](SECURITY.md).

It does **not** currently accept external pull requests, patches, code snippets intended for incorporation, or documentation contributions. Maintainers will close external pull requests without merging them. Do not attach proposed implementation code to an issue, because doing so does not grant the relicensing rights needed for the dual-license model.

A useful issue includes the target version/image digest, deployment profile, sanitized configuration, minimal reproduction, expected behavior, actual behavior, and relevant metadata-only logs. Never include API keys, tokens, prompts, responses, personal data, proprietary model artifacts, or internal topology.

If contributions open later, the project will publish a contributor license agreement before accepting them. The CLA must allow accepted work to be distributed under both `AGPL-3.0-only` and a commercial license while preserving contributor attribution. No contributor is asked to sign an unpublished agreement.

Participation in project spaces is subject to [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
