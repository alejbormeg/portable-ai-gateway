# Code of Conduct

Project spaces must remain respectful, inclusive, and focused on safe technical collaboration. Harassment, threats, discriminatory language, doxxing, deliberate disclosure of secrets or personal data, and sustained disruption are not acceptable.

Maintainers may edit or remove content, lock discussions, or restrict participation when behavior threatens people, data, or the project. Enforcement decisions should be proportionate, documented privately, and avoid publishing sensitive information.

Report conduct concerns privately to `{{CODE_OF_CONDUCT_CONTACT}}`. This placeholder must be replaced with a monitored channel before enabling public discussions or issue intake. Vulnerabilities belong in the process described by [SECURITY.md](SECURITY.md), not the conduct channel.
